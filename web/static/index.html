Giữ màn hình mở cho đến khi gửi xong. File được gửi nguyên bản, nhưng iPhone có thể tự đổi ảnh HEIC sang JPEG trước khi đưa cho trình duyệt. Sau khi gửi, nhãn bên cạnh mỗi file cho biết máy tính nhận được định dạng gì. Cách giữ file gốc

    Cách chắc chắn giữ HEIC, HEVC gốc từ iPhone
    1. Mở app Ảnh, chọn ảnh hoặc video, bấm Chia sẻ rồi chọn Lưu vào Tệp.
    2. Quay lại trang này, bấm Chọn ảnh hoặc video, chọn Chọn tệp và lấy file từ app Tệp.

    File lấy từ app Tệp được gửi đúng từng byte, iPhone không chuyển đổi.
